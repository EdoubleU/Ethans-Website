First time? How to get a GitHub token
  1. Go to github.com/settings/personal-access-tokens/new.
  2. Under Repository access, choose your site's repo only.
  3. Under Permissions → Contents, set Read and write.
  4. Set an expiration (90 days is fine), generate it, and paste it below.
  5. The token is never saved to disk — it lives in this tab's session only.

How this works
  1. Uses the same GitHub token as the Blog tab — save your repo settings there first.
  2. Photos are stored in a photos/ folder in your repo and served by GitHub Pages.
  3. A photos/manifest.json file tracks filenames, captions, and dates — the gallery page reads it to build the grid.
  4. Compress photos before uploading (aim for under 500KB) — smaller files load faster and keep your repo tidy.
  5. Deleting a photo removes it from the gallery and from your repo.
